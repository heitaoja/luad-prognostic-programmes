# Analysis specification for the revised study

Revision initiated on 2026-11-24 (Hong Kong time).

## Objective and version history

This retrospective revision asks whether four Hallmark transcriptional programmes show reproducible associations with overall survival in lung adenocarcinoma and whether a proliferation composite provides prognostic information beyond simpler proliferation measures. The original TCGA and GPL570 results were already known when this revision was designed. The four programmes, outcome and clinical adjustment set carry over from v1. The revision corrects the units of analysis and scoring and adds a separate model-transport experiment. This dated repository document records those decisions before running the revised analyses and examining outcome associations in any newly eligible cohort. It is an internal specification.

## Cohorts and outcome

- TCGA-LUAD is the discovery and model development cohort. Match clinical and expression records using the 12-character participant barcode where needed. Among eligible primary tumour samples with a clinical link, retain the first available vial in barcode order, with 01A preferred to 01B and 01C. Repeat the TCGA association using the last available vial. Check agreement of survival records among repeated samples before selection.
- GSE31210, GSE37745 and GSE50081 are the original external replication cohorts. Retain the published histological and follow-up restrictions. Outcome is time to death from any cause in months, with censoring at the last recorded contact. Treat cohort differences in the origin of follow-up as a limitation.
- GSE72094 and GSE68465 may enter an extension analysis if the platform map, patient and clinical links, adenocarcinoma histology, stage, OS units and status can be audited. Examine original recruiting sources for possible overlap with the original cohorts or between extensions. CPTAC-LUAD is a candidate RNA-seq extension under the same audit, with a predeclared focus on precision rather than a significance threshold. Report usable cases and deaths for every extension and record the disposition of candidates. The originally designated three-cohort synthesis remains separately identifiable.
- Report participant counts, deaths, covariate missingness, Kaplan–Meier median OS and reverse Kaplan–Meier median follow-up. Use complete clinical cases with a harmonised adjustment set. A common stage I–II analysis is a sensitivity analysis.

## Measurement and association

- Retain the four declared Hallmark programme definitions. Parse the GMT description field by position, including empty descriptions, and check all member sets against the platform matrix. Use midranks within ties for a sample-rank ssGSEA statistic with alpha 0.25. This prevents row order from breaking expression ties. Standardise each component within cohort, average the components equally and standardise the average for the association study. Report set and gene coverage.
- Fit separate Cox models per cohort and programme with stage, age and sex. Report the HR per SD, confidence interval and both score-level and global Schoenfeld tests. Use a stage-stratified Cox model and a three-degree-of-freedom spline as sensitivity analyses. Report mutual adjustment of the four programmes separately.
- Pool external log HRs by REML random effects with modified Knapp–Hartung confidence intervals. Report the original DerSimonian–Laird normal-approximation estimates as a sensitivity, alongside leave-one-cohort-out summaries. Apply Holm correction across the four external programme tests. Keep the TCGA estimates out of the external synthesis.
- Compare the proliferation composite with MKI67 expression and the E2F and G2/M components, all defined independently of outcomes. In the identical eligible patients, also estimate the composite increment conditional on each simple measure separately. These comparisons and single-gene effects are secondary.
- Use the public ABSOLUTE estimates released with the Aran pan-cancer study and distributed in the pinned TCGAbiolinks data object. Match exact TCGA specimen barcodes and compare the clinical-plus-score model with and without DNA-derived purity in the same patients. Report matched coverage, rank correlation and effect estimates with intervals.
- Evaluate random programmes matched for each gene set's size, gene abundance deciles and gene overlap between component sets. Treat paired survival outcome permutation in TCGA and the GSE31210 recurrence analysis as supporting checks.

## Model transport

Compare the clinical model with clinical plus the proliferation composite, MKI67, E2F or G2/M. Restrict scoring to an annotation-based gene intersection, with every member set reaching at least 80% measured coverage. For transport, average log-expression of duplicate features within the individual specimen. This implementation correction was made during technical review after a preliminary run that had used cohort-average probe selection. Derive component centring and scaling, coefficients and baseline cumulative hazard in TCGA only, then apply those fixed values to each external cohort. Measure discrimination by paired Harrell C differences with 1,000 resamples of the external patients with fixed predictions. Report 36-month calibration and IPCW Brier scores in cohorts with at least 10 deaths by the horizon and at least 10 patients still at risk at the horizon. Use the test-cohort calibration slope as a diagnostic. Platform offsets and differences in survival time origin can contribute to calibration errors.

## Independent RNA-seq evaluation

On 2026-11-24, before fitting CPTAC survival models, we specified a separate RNA-seq evaluation using the LinkedOmics CPTAC pan-cancer data freeze v1.2. The outcome and association programme definitions match the main analysis. Link tumour RNA-seq, clinical and OS records by unique case ID. Audit missing outcomes and clinical variables, deaths and reverse Kaplan–Meier follow-up. For each programme, report a Cox HR per within-cohort SD with stage I versus II–IV, age and sex. The two-level stage term limits the number of coefficients when the number of deaths is low. This analysis assesses direction and precision independently of the original and expanded array syntheses.

Audit compatibility with the fixed array transport gene list before prediction. If CPTAC measures every required gene, apply the corresponding TCGA-fitted models directly. Otherwise, use the intersection of that list and the CPTAC measurement, provided that MKI67 is present and every Hallmark set retains at least 80% coverage. For this sensitivity analysis, derive a separate TCGA reference and model fit on that reduced list and apply it to CPTAC. Use the same five model formulae, paired bootstrap and 36-month reporting criteria. Gene compatibility depends on expression availability and annotation. The CPTAC outcomes are only used to evaluate model performance.
