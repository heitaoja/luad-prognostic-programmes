# 预注册分析计划（SAP）

**项目**：肺腺癌中四类肿瘤转录程序的预后价值
**版本**：v1.0
**定稿时间**：2026-11-06（在第一例外部队列被读入分析之前）
**一致性**：本文件与 `R/02_score.R` 中的 `AXES` 定义一致；任何偏离见 `docs/changelog.md`。

---

## 0. 这份文件能保证什么、不能保证什么

诚实地说清楚预注册的范围：

- **可以保证**：程序的打分方式、主模型、协变量、切点策略、终点、合并方法、阴性对照与敏感性分析的清单，
  都是在**读入任何外部队列之前**写定的；外部队列没有参与任何选择。
- **不能保证**：四个程序来自 Hallmark 全集，但具体选哪四个，是在 TCGA 内做过一次探索性扫描后才定下来的
  （见 changelog 的时间戳）。因此 TCGA 的效应量估计**有选择偏倚**（winner's curse），
  只有外部队列的合并估计是干净的。
- 这条限制写在 README 与局限里，不藏着。

## 2. 暴露（四个程序，预先指定）

| 程序 | Hallmark 基因集 |
|---|---|
| proliferation | E2F_TARGETS, G2-M_CHECKPOINT, MYC_TARGETS_V1, MYC_TARGETS_V2 |
| hypoxia | HYPOXIA, GLYCOLYSIS |
| emt_stroma | EPITHELIAL_MESENCHYMAL_TRANSITION, TGF_BETA_SIGNALING, ANGIOGENESIS |
| immune | INFLAMMATORY_RESPONSE, INTERFERON_GAMMA_RESPONSE, INTERFERON_ALPHA_RESPONSE, ALLOGRAFT_REJECTION, COMPLEMENT |

**打分规则**（写死，不随结果调整）：

1. 每个基因集做 ssGSEA（α = 0.25，样本内秩次加权，得分除以基因数 N）；
2. 每个基因集分数在队列内 z 标准化；
3. 程序得分 = 成员基因集 z 分数的平均，再在队列内 z 标准化；
4. 不做跨队列的绝对值比较（跨队列只合并效应量）。

## 3. 主终点与主模型

- **主终点**：总生存（OS），单位月，事件 = 死亡。
- **主暴露**：程序得分，**连续变量，每 1 个标准差**。
- **主模型**：`coxph(Surv(os_time, os_event) ~ program + stage + age + sex)`。
- **判定**：HR 的 95% CI 不跨 1 且方向为 HR > 1 → 支持"该程序预后更差"。
- **多重比较**：4 个程序 × 4 个队列；主结论以随机效应合并的 p 为准，正文报告 I²。不做事后挑选。

## 4. 次要终点

| 分析 | 方法 | 定位 |
|---|---|---|
| 分期外增量价值 | ΔC-index（bootstrap 95% CI）、似然比检验、连续 NRI、36 个月 DCA | 次要但预注册 |
| 分期分层 | 各期内 Cox（校正年龄、性别） | 探索性 |
| 四程序互调 | 一个模型里同时放四个程序 | 探索性 |
| 校准 | 36 个月预测风险五分位 vs KM 观测 | 探索性 |

## 5. 切点策略

- 推断：**只用连续变量**，不切点。
- 可视化：KM 图用队列内中位数二分，图中注明"分组仅为可视化"。
- 最优切点：**禁止**。

## 6. 阴性对照

1. **随机基因集**：与真实基因集逐个匹配大小，重复 500 次（TCGA）/ 200 次（GSE31210）；
   经验 p = (#{HR_null ≥ HR_obs} + 1) / (B + 1)。
2. **标签置换**：随机打乱 (os_time, os_event) 1000 次，重拟合主模型。
3. 预期：随机基因集的 HR 中位数 ≈ 1；观测值应落在 99 分位之外。

## 7. 敏感性分析

| 变体 | 目的 |
|---|---|
| 只校正分期 | 排除协变量过拟合 |
| 排除 IV 期 | 排除晚期病人主导 |
| 平均 z 分数代替 ssGSEA | 评分方法依赖 |
| 1%/99% 缩尾 | 离群值依赖 |
| 无复发生存（仅 GSE31210） | 终点稳健性 |

判定：若主结论在多数变体中方向翻转，降级为"方法依赖"。

## 8. 写结果前就定好的三条红线

1. 不删不成立的队列；四个队列的 HR 全部进图。
2. 不把探索性分析写进主结论。
3. 阴性结果照写；免疫程序的阴性结论是本项目的结论之一。
